# 改良版テトリス

## ゲームの概要
Python と Tkinter で作成したブロック落ちパズルゲームです。落下するブロックを左右移動・回転させ、横一列を揃えてラインを消去し、ハイスコアを目指します。

## 動作環境
- OS: Windows
- Python: Python 3.10 以上
- 必要なライブラリ: 追加ライブラリ不要（Python 標準ライブラリの `tkinter` を使用）

## インストール方法
1. リポジトリを Clone またはダウンロードします。
2. 追加ライブラリのインストールは不要です。

## 起動方法
プロジェクトのルートフォルダーで以下のコマンドを実行してください。
`python tetris.py`

## 操作方法
- `←` / `→` キー（または `A` / `D` キー）: ブロックの左右移動
- `↓` キー（または `S` キー）: ブロックの落下（1マス落下ごとにスコア +1）
- `↑` / `W` / `Z` キー: ブロックの回転
- `P` キー: 一時停止 / 再開
- `R` キー: リスタート

## 追加・改良した機能

### 改良機能01：ネクストブロック表示
画面右側の `NEXT` 枠に次に出現するブロックを表示し、配置を先読みできるようにしました。

### 改良機能02：一時停止・リスタート機能
`P` キーでプレイの一時停止・再開、`R` キーで途中またはゲームオーバー後のやり直しができるようにしました。

### 改良機能03：スコア・レベル連動落下速度変更
同時消去ライン数に応じたスコア加算と、5ライン消去ごとのレベルアップ・落下速度上昇を実装しました。
